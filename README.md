# صانع التطبيقات (html-ila-apk)

تطبيق أندرويد يحوّل **كود HTML** (من Claude ولا Gemini) لتطبيق **APK** تثبّتو على تليفونك، من غير كمبيوتر ومن غير إنترنت.

## كيفاش نستعملو

1. قول لـ Claude ولا Gemini: «اعملّي [لعبة / تطبيق …] في **ملف HTML واحد** فيه CSS وJavaScript».
2. انسخ الجواب (حتى كامل، التطبيق ياخذ منو الكود وحدو).
3. في صانع التطبيقات: اكتب الاسم، اختار أيقونة، واضغط **📋 لصق الكود**.
4. اضغط **▶ جرّب** باش تشوفو قبل، ومن بعد **⚙️ حوّل إلى APK**.
5. اضغط **ثبّت**. التطبيق يتحفظ زادة في `Download/AppMaker`.

تنجم زادة:
- من تطبيق Claude: «مشاركة» ← **صانع التطبيقات** (الكود يدخل وحدو).
- **ملف ZIP** لمشروع فيه برشا ملفات (لازم فيه `index.html`).
- **رابط موقع**: يعمل تطبيق يحلّ الموقع هذاك.
- **تطبيقاتي** (☰): تلقى كل تطبيق عملتو. كي تبدّل فيه وتعاود «حوّل»، النسخة الجديدة تتثبّت **فوق القديمة** وما تفسخش المعطيات (السكور، الإعدادات…).

## ملاحظات

- كل تطبيق يتوقّع بمفتاح يتعمل مرة وحدة على تليفونك. كان تفسخ صانع التطبيقات وتعاود تثبّتو، التطبيقات القديمة لازم تتفسخ قبل ما تتثبّت نسخها الجديدة.
- كان طلعلك تحذير من Play Protect: «تثبيت على أي حال».

## كيفاش يخدم (للمطوّرين)

- `runner/`: تطبيق WebView صغير (Java). يتبنى في GitHub ويتحط داخل صانع التطبيقات كـ `template.apk`.
- `app/`: صانع التطبيقات (Kotlin + Compose). وقت «حوّل»:
  - يبدّل في `AndroidManifest.xml` (الملف الثنائي) اسم الـ package والاسم والنسخة (`engine/Axml.java`)،
  - يحط ملفات الموقع في `assets/www` والأيقونة،
  - يوقّع الـ APK (v1 + v2) بمكتبة `apksig` (`engine/ApkMaker.java`).
- GitHub Actions: يبني، يجرّب المحرّك، يثبّت ويجرّب كل شي على Android 14 افتراضي، ومن بعد ينشر الـ APK في **Releases**.
